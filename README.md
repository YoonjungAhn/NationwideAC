# Nationwide AC Project

This repository contains code and documentation for estimating air conditioning prevalence using various data sources and methodologies.

## Contents
- `Dewey_imputation.Rmd`: RMarkdown script for data imputation steps using the Dewey dataset.
- `Dataintegration_ACestimation.Rmd`: RMarkdown document for integrating multiple data sources.
- `Yes_ACesimtation_HPC.py`: Python script for running AC estimation for YES AC category
- `Alltype_ACesimtation_HPC.py`: Python script for running AC estimation for any types of AC.

## Instructions

Update all placeholder paths (`<your_path_here>`) to match your local environment before running the scripts.
